# Una aproximación a las Síntesis

Curso interactivo de síntesis de sonido de U-MA サウンド: teoría, laboratorios con audio en tiempo real (Web Audio), entrenamiento auditivo, glosario y progreso. Idiomas: es, en, de, ja.

Es una página estática: se abre `index.html` o se publica con GitHub Pages.

Los libros citados se mencionan como bibliografía recomendada y se describen con resúmenes propios. El recetario de patches tiene recetas propias de U-MA y algunos ejemplos citados del *Welsh's Synthesizer Cookbook* (Fred Welsh) con fines de estudio.
